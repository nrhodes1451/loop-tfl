1iInteraction notes
How it behaves
Setting From / To
Tapping either row opens the full-screen picker (1b) for that slot. Results are typeahead-filtered; each row shows the station's own step-free status so a dead end is visible before planning. Picking returns to entry with the slot filled and focus moved to the next empty slot. ⇅ swaps From and To in place. CTA stays disabled until both slots are set.
On success
Verdict banner first, timeline below (1c). Sticky header keeps From → To and the check time visible while scrolling. ↻ re-runs only the lift check, not the graph search.
On break
Never silently hide the path (1d): the attempted route stays, the failing leg is called out by station and cause, and everything after it dims and switches to a dashed connector — “unreachable”, not “fine”. Primary action replans excluding the failing node; secondary sets a watch on the lift. A permanent gap (1f) reads as structural, offers the nearest step-free station instead, and never suggests waiting.
On uncertainty
Missing live data downgrades the verdict to “probably step-free” (1e) rather than claiming success. Grey rings mark the unverified legs and name the last confirmed date. The footer always carries the unofficial-tool disclaimer and TfL's number.
Accessibility
Timeline is an ordered list, one item per leg, verdict as the first heading so screen readers hear the answer before the detail. Every status has a text label. Tap targets ≥44px, thumb-zone CTAs, visible focus rings. The graph canvas is an optional extra view, never the only path.
